# Cross-posting drafts — ready to paste

Cross-posting rule: **always set the canonical URL on Medium/LinkedIn/Hashnode back to
bukkyai.duckdns.org**, so Google keeps the original article as the ranking URL and you don't
create duplicate content. Steps differ per platform (below).

Each article file below is a full body you can paste (markdown). Add your intro line, paste,
add the canonical, publish.

---

## Publish steps per platform

### Medium
1. Create a story, paste the body markdown.
2. After pasting, click the `⋮` (More options) → set **Canonical link** to the bukkyai URL.
3. Add tag(s): `Web Design`, `Small Business`, `Entrepreneurship`.
4. Publish. Medium's import tool also works from the article URL, but copy-paste + canonical
   gives you full control.

### LinkedIn (Articles)
1. Start a post → select "Write article".
2. Paste the body, drop in a cover image (`/og/*.png` on bukkyai or an exported screenshot).
3. LinkedIn has no canonical field — **edit the pasted content** to add
   `First published at bukkyai.duckdns.org` as a link line at the bottom, and make the top
   heading link out. Keep the article shorter for LinkedIn (see notes).
4. Publish, then reshare the article to your feed with a one-line hook.

### Hashnode
1. Create a new post → paste body into the markdown editor.
2. In the post settings, set **Canonical URL** to the bukkyai URL.
3. Tags: `webdev`, `websites`, `ai`.
4. Publish.

## What NOT to do
- Don't publish the exact same text on two platforms without a canonical — that's duplicate
  content and can hurt the bukkyai ranking.
- Don't put the bukkyai link only in your profile. Put it in the article body (LinkedIn) or
  canonical (Medium/Hashnode) where Google reads it.
- Don't post every article everywhere. 2 platforms max per article; save some for the launch push.
