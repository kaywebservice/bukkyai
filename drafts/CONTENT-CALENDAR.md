## Cadence rules
- Publish to bukkyai first. Wait 24h. Then cross-post with canonical.
- Each article needs an OG image (see `public/og/*.png` after build) — no OG card = no clicks.
- Track in Search Console weekly: impressions for target keywords; promote whichever post is gaining.

## Launch push (one-time)
- Show HN: the "built from one sentence" story + playground link.
- Product Hunt: launch page with playground + made-with gallery.
- Reddit r/smallbusiness + r/webdev: "I built a thing" honest post (not a link drop).
- Then return to weekly cadence above.
